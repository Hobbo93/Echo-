# Echo Roblox Map Builder

Echo's **Roblox Map Builder** designs maps on your PC: obbies, cities, battle arenas, forests and islands, race tracks and houses.

## Ask for a map
- In Echo HQ, pick **Roblox Map Builder** and type something like *build a snowy obby with 20 stages*.
- On Telegram: `/roblox a big night city` (or just "build a roblox desert arena"). `/maps` lists your maps.

Words Echo understands: obby, city, arena/battle, forest/island, race track, house; snow, desert, lava, candy, night, space, jungle; small, big.

## Get it into Roblox Studio
1. **Automatic:** the Echo plugin is in your Roblox Plugins folder. Open Roblox Studio with a place (a Baseplate is fine). The first time, Studio asks if the plugin can connect to 127.0.0.1: click **Allow**. Every map you ask for is then built in your place within a few seconds. The **Echo Builder** button on the Plugins tab turns it on or off. Press Ctrl+Z to undo a map.
2. **By hand:** every map is also saved in `Echo_roblox\maps` in your user folder. Drag the `.rbxmx` file into Studio.

To reinstall the plugin, run `py echo_roblox.py --install-plugin` in the Echo folder.

Echo never publishes a game or spends Robux. You publish from Studio yourself.
