# Project summary
Echo: a personal AI "company" on the owner's Windows PC (Adelaide). 15 AI employees run on a
local Ollama model (`llama3.2`) and are reached through a 3D office (`Office.html` via
`echo_server.py`, http://127.0.0.1:5000), Telegram and a Twilio phone line.
Businesses: Furventure Shopify store (dog products), YouTube/Instagram/TikTok short clips via
OpusClip, website leads for southern Adelaide businesses (built in Base44), Roblox maps,
paper/live trading through Alpaca.

## Goals
- Echo does real work for each business, but every outside action waits for the owner's Yes.
- Everything free/local where possible; paid services only when clearly worth it.
- Claude works with long-term memory and low token use (this `memory/` folder).
